# Phase 2: Owl Dashboard — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, chosen for this session) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Owl, the Next.js 15 dashboard for the Cerberus engine, as a separate server under `owl/`: agents table + editor, live decision stream, policy viewer/validate, settings — all proxied through Next route handlers so the admin token never reaches the browser. This session's stated goal ("install and build") is Tasks 1–2; Tasks 3–14 complete the phase.

**Architecture:** Browser → Next.js route handlers (`owl/app/api/*`) → engine admin API with `CERBERUS_URL` + `CERBERUS_ADMIN_TOKEN` from server-only env. One zod schema (`owl/lib/schema.ts`) mirrors the engine's data JSON — no second data model. SSE proxied at `/api/events`; the engine's replay-50 ring makes reconnects cheap.

**Tech Stack:** Next.js 15 App Router · TypeScript `strict` · Tailwind v4 · shadcn/ui (new-york) · TanStack Query + Table · react-hook-form + zod · next-themes · sonner · lucide-react · Vitest · Playwright. npm only (pnpm/bun/yarn not installed on this machine; local Node v23.11.0, `node:22-alpine` in Docker).

**Spec:** `docs/ROADMAP.md` §"Phase 2 direction" (pinned stack + architecture rules 1–7), `docs/CONVENTIONS.md` §TypeScript/Owl, engine API verified in `internal/server/{server,admin,events}.go`.

**Executes in:** worktree `.claude/worktrees/phase2-owl`, branch `feat/phase2-owl` (already created, clean, at `edd41de`).

## Global Constraints

- Browser never talks to the engine directly; `import 'server-only'` in `lib/engine.ts`; token only in route handlers (`owl/.env.local`, gitignored; ship `.env.example`).
- Engine contract (verified against `internal/server/admin.go`, `events.go`):
  - `GET /v1/admin/data` → data JSON + `X-Cerberus-Epoch` header
  - `PUT /v1/admin/data` → `{epoch}`; invalid → **422** `{"error": ...}`, old snapshot stays live
  - `POST /v1/admin/policy/validate` body `{"rego"}` → `{ok, errors[]}` (422 when invalid)
  - `GET /v1/audit?key_id&stage&decision&rule_id&since(RFC3339)&limit` → `Event[]`
  - `GET /v1/events` → SSE, frames `event: decision` + one JSON `data:` line, `: ping` every 15s
  - Auth: `Authorization: Bearer $CERBERUS_ADMIN_TOKEN` on all `/v1/*` routes
  - `Event` JSON: `{id, time, stage, key_id, subject, decision, rule_id, reason, epoch, cached, latency_us, args?}`
- Data model = engine's `data.template.json` exactly: `config{bypass_unknown_teams, bypass_unknown_keys}`, `teams{}`, `agents{}`, `blocked_patterns[]`, `domains{}` (pass-through object), `_comment` allowed anywhere; unknown top-level fields rejected by the engine.
- Agent fields: `name, description?, team_id?, allowed_models?, allowed_tools?, restricted_tools?, allowed_tool_calls?, restricted_tool_calls?, tool_argument_constraints?, budget_limit?, risk_tier?, log_level?, masking?`
- Masking rule: `{pattern, transform: redact|mask|hash, scope: args|response|""}`; scope `""` = both.
- Tool argument constraint forms (zod union): bare `string[]` | `{type:"allowlist", values: string[]}` | `{type:"regex_allow", patterns: string[]}` | `{type:"range", min: number, max: number}` — keyed `tool → arg → form`.
- shadcn: `components/ui/*` generated only, never hand-edited; `cn()` from `lib/utils`; theme via CSS variables in `globals.css`; dark mode via `next-themes`; toasts = sonner; one shared `DataTable` over TanStack Table; `Skeleton` for loading, `Alert` for errors, one shared `EmptyState`.
- Conventional Commits, one task = one commit; commit trailer `Co-Authored-By: Claude Code <noreply@anthropic.com>`.
- Node ≥22; no dependencies beyond the roadmap-pinned list.

## Review Focus

1. **Engine unreachable** → every page shows an `Alert` (e.g. "Engine unreachable"), never a blank page or crash. Pinned: vitest on the fetch-error mapping helper (Task 4).
2. **Engine rejects a PUT (422)** → editor shows the engine's validation message verbatim and keeps editing (no optimistic overwrite of live data). Pinned: vitest on schema pre-gate + error path (Tasks 3–4).
3. **SSE through the proxy must not buffer** and must reconnect: `EventSource('/api/events')` re-issues on drop; engine replays last 50 so gaps self-heal. Pinned: Playwright flow 3 (Task 13) + curl through the proxy (Task 5).
4. **Key IDs are 64-hex hashes** → tables truncate with copy-on-click, never wrap layout; editor URL `/agents/[keyId]` uses the raw ID. Pinned: Playwright flow 1 renders the seeded hash key (Task 13).
5. **Fail-closed flip is destructive** (deny-all for unknown keys/teams) → `/settings` requires a red confirm dialog before PUT. Pinned: Playwright flow 2 asserts dialog appears (Task 13).
